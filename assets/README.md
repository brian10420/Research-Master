# Figures — claims tables (SCIENTIFIC_RULES §9)

Every figure in this directory is hand-written SVG, regenerated by hand, never exported from a tool.
§9 requires that every label, number, threshold, direction and status on a figure trace to a source
line and be listed as a claim; nothing the source does not state appears on a figure. The tables
below are those lists, one per figure, as written by the illustrator of each figure on 2026-11-02 and
verified by a fresh-context checker that drew none of them (verdict recorded in `CHANGELOG.md` 0.4.0).
Line numbers are pinned to the working tree of 2026-11-02; `assets/team-map.svg@HEAD` in the
team-flows table means the v2 map at commit `23bf56d`, the version that figure was drawn from.

Palette and line grammar (shared by every figure): strokes `#435954`; card fills `#FDFEFD` /
`#E4E8E6` / `#F3F5F4`; text `#1D2523`, secondary `#5A6663`; teal `#0F6B62` on `#E3EDE9` = the shared
session; indigo `#41507A` on `#E6EAF3` = isolated, dispatched context; amber `#A9761C` only on the
`regression-guardian` gate. Solid arrow = a hand-off carrying work; thin line = membership; dashed =
the context boundary and nothing else; dotted = a role asking the operator to move the effort switch.

To re-render a preview: `inkscape --export-type=png --export-width=1400 assets/<figure>.svg -o <out>.png`.
