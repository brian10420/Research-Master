# Figures — claims tables (SCIENTIFIC_RULES §9)

Every figure in this directory is hand-written SVG, regenerated by hand, never exported from a tool.
§9 requires that every label, number, threshold, direction and status on a figure trace to a source
line and be listed as a claim; nothing the source does not state appears on a figure. The tables
below are those lists, one per figure, as written by the illustrator of each figure on 2026-11-02 and
verified by a fresh-context checker that drew none of them (verdict recorded in `CHANGELOG.md` 0.4.0).
Line numbers are pinned to the working tree of 2026-11-02; `assets/team-map.svg@HEAD` in the
team-flows table means the v2 map at commit `23bf56d`, the version that figure was drawn from.
The nine scenario sections at the end (`scenarios/NN-<slug>.svg`) were written by each figure's
illustrator on 2026-11-03 and verified by three fresh-context checkers that drew none of them
(verdicts in `CHANGELOG.md` 0.7.0); their line numbers are pinned to the working tree of 2026-11-03.

Palette and line grammar (shared by every figure): strokes `#435954`; card fills `#FDFEFD` /
`#E4E8E6` / `#F3F5F4`; text `#1D2523`, secondary `#5A6663`; teal `#0F6B62` on `#E3EDE9` = the shared
session; indigo `#41507A` on `#E6EAF3` = isolated, dispatched context; amber `#A9761C` only on the
`regression-guardian` gate. Solid arrow = a hand-off carrying work; thin line = membership; dashed =
the context boundary and nothing else; dotted = a role asking the operator to move the effort switch.

To re-render a preview: `inkscape --export-type=png --export-width=1400 assets/<figure>.svg -o <out>.png`.

### Changes from v1 and why

- v1's "blind-reviewer · PDF only" is dropped: `core/roles/blind-reviewer.md:30` says "the manuscript (PDF or sources)". The redraw shows the bundle crossing a context boundary instead (rows 29–32).
- v1's "step 5 runs only before a defense — otherwise the deck ships at step 4" is dropped. No source states the second half. The arrow now carries only "for a defense" (`core/roles/README.md:115`).
- v1's Stuck lane chained "role is stuck → … → ask you to run /effort max → you lower it back to high" under "escalate the method before the effort". That contradicts `core/roles/README.md:89–90` ("never by \"it got stuck\"") and `templates/research-master.overlay.template.md:124–125` ("not by raising effort"). Lane 6 now draws two separate rows: a stuck role changes method; only an unbounded-judgement step asks for `/effort max`, then for `/effort high` (or the session default). For the same reason the lane title is "method first, not effort" rather than the brief's wording "method before effort".
- v1's lane titles ("Build & test an idea", "Write the paper", "Learn your own results", "Present it to others") are replaced by the flow names in `core/roles/README.md:104–124`.

It is a source for layout, ordering, call-line form and the illustrative ask only, never for a claim about the system.
Glyph grammar and palette follow `assets/README.md:11–15` and TF, as follows. A teal card with `/` is a skill in your session. An indigo card with a doubled left edge is a dispatched subagent. The diamond is the sparring gate. A grey box is a step, script or record. A solid arrow is a hand-off. The dashed line is the context boundary and nothing else. Numbered discs give the step order. This figure has no `regression-guardian`, so no amber hexagon. Positions, sizes and the layout of each card's contents are the illustrator's choice and carry no meaning.
The bear images are the character PNGs (`assets/roles/illustrations/<role>.png`). Each one is downscaled to 192 px, quantized to ≤ 128 colours, embedded as a `data:` URI, and clipped to its own pale rounded square (svg l. 8–12; each clip rect measured on the 192-px quantized PNG, the conductor's with a 2.5-px inset). Per `assets/README.md:392–395`, "These are portraits, not figures: they state nothing", so no row below rests on a bear image.
The figure is generic. Its discipline card is the card format of DR, not any particular card; it draws no field-specific content, institution, committee, hospital, person or number, and its only paths are repository paths.
